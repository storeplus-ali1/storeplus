# دليل النسخ الاحتياطي والاستعادة

- يعمل تلقائياً كل يوم على GitHub Actions (مجاني): نسخة من قاعدة البيانات وصور الإيصالات، مشفّرة AES-256.
- مفتاح التشفير محفوظ في الخزنة. بدونه لا يمكن فك النسخة.
- كل تشغيل يجرّب الاستعادة تلقائياً للتأكد أن النسخة سليمة.
- تظهر الملفات في GitHub > Actions > daily-backup > Artifacts (تُحفظ 30 يوماً).
- فك التشفير: openssl enc -d -aes-256-cbc -pbkdf2 -in db-التاريخ.dump.enc -out db.dump ثم pg_restore.
- التكلفة: صفر. Actions للمستودع العام مجانية.
